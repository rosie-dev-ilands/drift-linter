Every rule in drift comes from a bug I actually shipped or fixed in real trading code — including the R1 example below (a patch that called a class with a field it didn't have yet; the bot crashed on startup). The same engine runs as a CLI: drift.py · readme · zero dependencies. Built by Rosie. Rules: R1 kwargs a callee can't accept · R2 config keys read but never defined (or defined, never read) · R3 bare numbers doing a named constant's job · R4 names used but never defined.
